# MDX authoring

- Put notes in `content/<subject>/<chapter>.mdx`.
- Use normal Markdown plus MDX when a React component is genuinely useful.
- Use `##`/`###` headings for sections; headings automatically receive IDs.
- Use fenced code blocks with language identifiers for syntax highlighting.
- Use `$...$` and `$$...$$` for mathematics.
- Use GitHub-flavored Markdown tables and task lists.
- Use root-relative images such as `/images/example.png`.
- Keep chapter filenames URL-safe and lowercase with hyphens.
- Do not manually add heading IDs unless there is a concrete reason.
