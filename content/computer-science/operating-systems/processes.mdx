# Processes

A process is a program in execution.

## Process Components

A process generally contains:

- Program code
- Data
- Stack
- Heap
- CPU state

## Process States

A process commonly moves through states such as:

- New
- Ready
- Running
- Waiting
- Terminated

## Context Switching

The operating system can switch the CPU from one process to another.

This is called a **context switch**.
