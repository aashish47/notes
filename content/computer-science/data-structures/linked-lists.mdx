# Linked Lists

A linked list is a linear data structure made up of nodes.

## Node

Each node typically contains:

- Data
- A reference to the next node

## Types

1. Singly linked list
2. Doubly linked list
3. Circular linked list

## Advantages

- Dynamic size
- Efficient insertion and deletion at known positions

## Disadvantages

- No constant-time random access
- Additional memory is required for references
