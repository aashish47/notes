# Arrays

An array is a collection of elements stored in contiguous memory locations.

## Basic idea

Arrays allow elements to be accessed using an index.

For example:

- `A[0]` → first element
- `A[1]` → second element
- `A[2]` → third element

## Time Complexity

| Operation | Complexity |
| --------- | ---------- |
| Access    | O(1)       |
| Search    | O(n)       |
| Insertion | O(n)       |
| Deletion  | O(n)       |

## Key Points

- Elements are accessed using indices.
- Contiguous memory enables fast random access.
- Insertion and deletion can require shifting elements.
