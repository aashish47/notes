# Motion

Motion describes how the position of an object changes with time.

## Position

Position specifies where an object is located relative to a reference point.

## Velocity

Velocity describes the rate of change of position.

$$
v = \frac{dx}{dt}
$$

## Acceleration

Acceleration describes the rate of change of velocity.

$$
a = \frac{dv}{dt}
$$

## Key Idea

Position → Velocity → Acceleration

Each represents a different level of change with respect to time.
